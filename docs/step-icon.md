# アプリアイコン設定

## 目的

ホーム画面・共有シートに表示されるアプリアイコンを  
`icon_1024x1024.png` に変更する。

---

## 背景知識

### AppIcon.appiconset の仕組み

Xcode 26 のアイコン設定は `Assets.xcassets/AppIcon.appiconset/` 以下で管理される。  
`Contents.json` に3つのスロットが定義されている：

| スロット | 用途 |
|---------|------|
| `universal`（指定なし） | ライトモード・デフォルト |
| `dark` | ダークモード時のアイコン |
| `tinted` | ユーザーがアクセントカラーを変えたとき |

dark・tinted は省略可能。未設定の場合は iOS が universal にフォールバックする。

### なぜ Xcode GUI が不要か

`Contents.json` に `"filename"` を追加し、画像ファイルを同フォルダに置くだけで設定できる。  
Claude Code がファイルシステムを直接操作できるため、Xcode での GUI 操作は不要。

---

## 実施内容

1. `icon_1024x1024.png` を `AppIcon.appiconset/` にコピー
2. `Contents.json` の universal スロットに `"filename": "icon_1024x1024.png"` を追加

---

## 確認ポイント

- [ ] Xcode で ▶ リビルド後、シミュレーターのホーム画面でアイコンが変わる
- [ ] 実機のホーム画面でアイコンが変わる
- [ ] 共有シートにも新しいアイコンが表示される

---

## 学んだこと・メモ

- アイコンは 1024×1024px の PNG 1枚で全サイズに対応（Xcode が自動でリサイズ）
- dark・tinted 用に別デザインのアイコンを用意することもできる
- アイコン変更後は**再インストール**（またはアプリ削除 → 再ビルド）が必要な場合がある
