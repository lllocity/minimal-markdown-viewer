# Step 00: Xcode インストール

## 目的

iOS アプリ開発に必須の統合開発環境「Xcode」を Mac にインストールする。

Xcode は Apple が提供する公式ツールで、ビルド・シミュレータ・実機転送・署名・App Store 申請まですべてここで行う。

---

## 前提条件

- Mac（Apple Silicon または Intel）
- macOS 14（Sonoma）以上が望ましい
- 空きディスク容量：**約 15GB 以上**
- Apple ID（無料）：持っていない場合は [appleid.apple.com](https://appleid.apple.com) で作成

---

## 手順

### 1. Mac App Store を開く

Dock またはランチパッドから **「App Store」** を起動する。

### 2. Xcode を検索してインストール

1. 検索バーに `Xcode` と入力
2. 「Xcode」（Apple 製、開発者ツール）を選択
3. 「入手」または「インストール」をクリック
4. Apple ID でサインイン（確認ダイアログが出たらサインイン）
5. ダウンロードが始まる（ファイルサイズが大きいため、**30分〜数時間**かかる場合がある）

> [!TIP]
> ダウンロード中は Wi-Fi が安定した環境で放置してよい。完了後に次の手順へ進む。

### 3. 初回起動と追加コンポーネントのインストール

1. App Store のインストールが完了したら **Xcode を起動**
2. 初回起動時に「Install additional required components?」と聞かれたら **「Install」** をクリック
3. パスワードを求められたら Mac のログインパスワードを入力
4. 追加コンポーネントのインストールが完了するまで待つ（数分）

### 4. ライセンス同意

初回起動時にライセンス同意画面が表示されたら **「Agree」** をクリック。

### 5. バージョン確認

Xcode が起動し、Welcome 画面が表示されれば成功。

バージョン確認方法:
- メニューバー → **「Xcode」→「About Xcode」** でバージョンを確認
- 2026年5月時点では **Xcode 26.5** が最新

---

## プラットフォームコンポーネントの選択

初回起動時またはコンポーネント選択ダイアログが表示されたら：

| コンポーネント | 選択 | 理由 |
|--------------|------|------|
| macOS | Built-in（変更不可） | - |
| **iOS** | **✓ チェックする** | iPhone アプリ開発に必須（約 10.6 GB） |
| watchOS | 不要 | Apple Watch アプリは作らない |
| tvOS | 不要 | Apple TV アプリは作らない |
| visionOS | 不要 | Vision Pro アプリは作らない |
| Predictive Code Completion Model | 任意 | Xcode 内 AI コード補完（2 GB）。不要なら外してよい |

---

## 確認ポイント

- [ ] Xcode が起動して Welcome 画面（「Create New Project」などのボタンがある画面）が表示された
- [ ] Xcode のバージョンが **26.5** である
- [ ] iOS プラットフォームのダウンロードが完了している

---

## よくあるエラーと対処法

### 「ストレージが不足しています」

- ディスクの空き容量が 15GB 未満の場合に発生
- 不要なファイルや古いアプリを削除してから再試行

### ダウンロードが途中で止まる

- App Store アプリを完全に終了（⌘+Q）してから再起動
- Apple ID でいったんサインアウト → サインインしてから再試行

### 「このソフトウェアをインストールするには macOS XX が必要です」

- macOS が古い場合に発生
- システム設定 → 「ソフトウェアアップデート」で macOS を最新にしてから再試行

---

## 学んだこと・メモ

- Xcode は非常に大きなツールだが、iOS 開発には欠かせない。VSCode との違いは「ビルド・シミュレータ・署名」まで一体化している点
- Swift ファイルの編集は VSCode + Claude Code でも可能（ハイブリッドワークフロー）
- **無料の Apple ID でも実機インストールは可能**。ただし証明書の有効期限が 7 日間のため、週 1 回 Xcode から再ビルドが必要になる（Step 09 で詳述）
