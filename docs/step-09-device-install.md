# Step 09: 実機インストール（無料アカウント）

## 目的

iPhone に直接アプリをインストールして実機で動作確認する。  
無料の Apple ID で署名・転送する方法を学ぶ。

---

## 背景知識

### 無料アカウントの制約

| 項目 | 無料 Apple ID | Apple Developer Program（$99/年） |
|------|-------------|----------------------------------|
| 実機インストール | ✅ 可能 | ✅ 可能 |
| 証明書の有効期限 | **7日間** | 1年間 |
| 同時インストール台数 | 3台まで | 無制限 |
| App Store 配布 | ❌ 不可 | ✅ 可能 |

7日後にアプリが起動できなくなったら、Xcode から再ビルドするだけで延長できる。

### 実機インストールの流れ

```
iPhone を USB で Mac に接続
  └─▶ Xcode でデバイスを選択
      └─▶ ▶ でビルド & 転送
          └─▶ iPhone の「設定」で開発者を信頼
              └─▶ アプリ起動 ✅
```

---

## 手順

### 1. iPhone を Mac に接続する

USB ケーブルで iPhone と Mac を接続する。  
iPhone に「このコンピュータを信頼しますか？」と表示されたら **「信頼」** をタップ。

### 2. Xcode でデバイスを選択する

Xcode 上部のビルドターゲット（今は `iPhone 17 Pro` などシミュレーター名が表示されている）をクリックし、  
接続した iPhone（自分の端末名）を選択する。

### 3. ビルド & 転送する

**▶ ボタン**を押す。  
初回は Xcode が証明書を自動作成・署名してから転送する（数分かかる場合がある）。

途中で「codesign がキーチェーンのキーへアクセスしようとしています」というダイアログが複数回出ることがある。すべてに **Mac のログインパスワード**を入力して「許可」または「常に許可」を選ぶ。毎回聞かれるのが煩わしければ「**常に許可**」にしておくと次回から不要になる。

### 4. iPhone でアプリを信頼する

初回インストール時、iPhone 側で信頼の設定が必要。

1. iPhone の **「設定」** を開く
2. **「一般」** → **「VPN とデバイス管理」**
3. 開発者の Apple ID（メールアドレス）をタップ
4. **「〇〇を信頼」** をタップ

これで iPhone からアプリを起動できるようになる。

### 5. アプリを起動して確認する

iPhone のホーム画面に「Minimal Markdown Viewer」が追加されているので起動する。  
「ファイルを開いてください」の待機画面が表示されれば成功。

---

## 確認ポイント

- [x] iPhone のホーム画面にアプリが表示される
- [x] アプリを起動して待機画面が表示される
- [ ] Google Drive の `.md` ファイルを「アプリで開く」で開ける（Step 10 で詳しくテスト）

## よくあるエラーと対処法

### 「Could not launch ... No devices are available」

- USB ケーブルを抜き差しして再接続
- iPhone のロックを解除した状態で接続する

### 「Untrusted Developer」エラーでアプリが起動しない

- Step 4 の「VPN とデバイス管理」で信頼の設定がまだ
- 設定 → 一般 → VPN とデバイス管理 → Apple ID を信頼

### 「Signing for ... requires a development team」

- Xcode で Team が設定されていない
- プロジェクト設定 → Signing & Capabilities → Team に Apple ID を設定

### 7日後にアプリが開かなくなった

- 無料証明書の有効期限切れ
- iPhone を Mac に接続して Xcode から ▶ で再ビルドするだけで延長される

### ビルドエラー「Failed to register bundle identifier」

- Bundle ID `io.github.lllocity.Minimal-Markdown-Viewer` が他のアカウントと競合している可能性
- Bundle ID の末尾に数字を追加して変更（例: `io.github.lllocity.Minimal-Markdown-Viewer-1`）

---

## 学んだこと・メモ

- 無料アカウントでも実機テストは十分できる。毎週の再ビルドを習慣にすれば問題ない
- 「VPN とデバイス管理」での信頼設定は初回のみ。同じ Apple ID で再ビルドした場合は不要
- 実機では Google Drive が使えるため、Step 10 で本番ワークフローをテストできる
- Apple Developer Program（$99/年）に加入すると証明書が1年間有効になり、再ビルドの手間がなくなる
