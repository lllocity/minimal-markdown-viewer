# Step 08: シミュレーターでのテスト

## 目的

iOS シミュレーター上で `.md` ファイルを「アプリで開く」フローが動くことを確認する。  
実機インストール（Step 09）の前に、基本動作を安全な環境で検証する。

---

## 背景知識

### iOS シミュレーターとは

Mac 上で動く仮想の iPhone/iPad。実機がなくてもアプリの動作確認ができる。  
ただし **Google Drive アプリはシミュレーターにインストールできない**ため、  
代わりに **Files アプリ（ファイルアプリ）** を使って「アプリで開く」フローをテストする。

### シミュレーターへのファイル送付方法

Mac から `.md` ファイルをシミュレーターに送る最も簡単な方法：

**Finder からシミュレーター画面にドラッグ＆ドロップ**  
→ シミュレーターの Files アプリ「ダウンロード」フォルダに自動保存される

---

## テスト用ファイル

プロジェクトルートに `test.md` を用意済み（`minimal-markdown-viewer/test.md`）。  
このファイルを使ってテストする。

---

## 手順

### 1. アプリをシミュレーターで起動する

Xcode で **▶ ボタン**を押してシミュレーターを起動する。  
「ファイルを開いてください」の待機画面が表示されることを確認。

### 2. test.md をシミュレーターに転送する

1. Mac の Finder で `minimal-markdown-viewer/test.md` を見つける
2. **シミュレーターが前面に表示された状態**で、`test.md` をシミュレーターの画面にドラッグする
3. Files アプリが開き、「ダウンロード」フォルダに `test.md` が保存される

> [!TIP]
> ドラッグしてもシミュレーターに反応しない場合は、一度シミュレーター画面をクリックして前面に出してから再試行する。

### 3. Files アプリから「アプリで開く」

1. シミュレーター上の **Files アプリ**を開く（ホーム画面の「ファイル」）
2. **「ダウンロード」** フォルダを開く
3. `test.md` を**長押し**
4. 表示されるメニューから **「共有」** を選択
5. 共有シートに **「Minimal Markdown Viewer」** が表示されたらタップ

### 4. 表示を確認する

| 確認項目 | 期待する表示 |
|---------|------------|
| ナビゲーションバー | `test.md` というファイル名 |
| H1 見出し | 大きなフォントで「テスト見出し」 |
| H2 見出し | 中サイズで各セクション名 |
| 太字・斜体 | **太字** / *斜体* が反映 |
| コードブロック | 等幅フォント・グレー背景 |
| リスト | 箇条書きが表示 |
| 引用 | 左ラインが入った引用スタイル |
| リンク | タップで Safari が開く |

---

## 確認ポイント

- [ ] シミュレーターで「ファイルを開いてください」の待機画面が表示される
- [ ] Finder からのドラッグで test.md が Files アプリに保存された
- [ ] Files アプリ → 長押し → 共有 → Minimal Markdown Viewer でファイルが開く
- [ ] Markdown が正しくレンダリングされて表示される
- [ ] ナビゲーションバーにファイル名 `test.md` が表示される

---

## よくあるエラーと対処法

### 共有シートに「Minimal Markdown Viewer」が表示されない

- Step 03 の Document Types / UTI 設定が正しいか確認
- `⌘+Shift+K`（クリーンビルド）→ ▶ で再ビルド
- シミュレーターを再起動（Simulator メニュー → Device → Restart）

### ドラッグしてもシミュレーターに反応しない

- シミュレーターを前面に出してから再試行
- Xcode と Simulator が最新か確認

### Markdown がレンダリングされず生テキストで表示される

- `import MarkdownUI` が抜けていないか `MarkdownView.swift` を確認

### アプリが開いた瞬間にクラッシュする

- Xcode のデバッグコンソールにエラーメッセージが表示されるので確認
- `DocumentViewModel.load()` のエラーハンドリング部分を確認

---

## 学んだこと・メモ

- シミュレーターは Google Drive が使えないため Files アプリで代替テストを行う
- Finder からシミュレーターへのドラッグ＆ドロップは Xcode 14 以降で対応
- 実際の Google Drive での動作確認は Step 10 で実施
- `⌘+Shift+K`（クリーンビルド）：ビルドキャッシュを削除して最初からやり直す。謎の挙動が起きたときに試す
